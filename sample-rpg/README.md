# The Hollowbrook Summer: a Twine-style RPG for the SDL3 player

Ten days in a river town before the Midsummer Trials. Build a character, spend the days of
the week on work, study and favours, and arrive at the Trials able to do what they ask. About
a quarter of an hour of play; the choices matter and no two summers are the same.

```sh
make varis varis-sdl                          # from the repository root (needs SDL3 packages)
bin/varis-sdl sample-rpg/presentation.json    # the game
cd sample-rpg && ../bin/varis main.lua 7      # the same game in a terminal (--bot plays itself)
cd sample-rpg && ../bin/varis test            # author tests, including a bot playthrough
```

The art and audio are generated placeholders (`python3 tools/gen_assets.py`); replace a file in
`assets/` with finished art of the same name and nothing else changes. Fonts are the system's
(Arial, DejaVu Sans); name a `font` in `presentation.json` to ship one.

## What it shows

| Area | Where |
| --- | --- |
| Character creation with a name typed in a scene reaching the world (`procedure` + scene `effect` beat), a transactional "start over" | `scenes/prologue.varis`, `content/creation.varis` |
| Stat gates with reasons (`require … because`), complementary "have a go" choices | `content/forge.varis`, `docks.lua`, `quarry.lua`, `trials.lua` |
| Relations: recursion (`reachable`, gossip `knows_of`), stratified negation (`isolated`, endings), aggregates (`count`, `sum`, `max`), zero-arity rules (`evening`, `festival_eve`), guards | `world.lua` |
| Decks and drawing, sticky/priority/order/cooldown/non-repeatable storylets, parameterised instances (riddles, jobs, shop, accusations) | `content/*.varis` |
| Templates: `{#select}`, `{#plural}`, `{#if query}`, names for symbols | `content/hub.varis`, `creation.lua`, `qualities.varis` |
| Scenes: input, menu, jump, call, say with expressions, stage slots, music; repeat ladders so training reads differently each time | `scenes/`, `content/*.varis` |
| Actions with `once_per :day`, events, schedules and handlers, `defer` for achievements | `content/events.varis` |
| Qualities with bounds and labels; `observe` for toasts; save, load and replay | `qualities.varis`, `game.lua` |
| Localisation: 454 messages, a French draft, a built pack, language switch in the pause menu | `l10n/`, `packs/fr` |

## How the game plays

- Each day has three parts (morning, afternoon, evening). An activity uses one; walking is free;
  sleeping at the house starts the next day. Day ten's evening begins the Trials.
- Stamina gates strenuous work; coins buy a few helpful things and the 30-coin entry fee.
- The four stats (Strength, Wits, Charm, Grit) rise by training and open doors: the anvil at 50
  Strength, the locked shelf at 60 Wits, the open-mic at 40 Charm, the bridge three ways.
- People remember: Mara, Pell, Tilly and Hask trust you more as you help them, and trust unlocks
  teachers, clues and, at the end, patrons. Gossip travels along friendships.
- A banner goes missing on day six. Three clues and the right name settle it.
